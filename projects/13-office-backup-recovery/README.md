# Office Backup and Recovery

Plan and rehearse recovery for a simulated office file share. Target a 24-hour recovery point and a 60-minute recovery time.

## Career context

At Academia de Seguridad Pública de Baja California and CEFPPBC, I planned network and infrastructure work, managed server and storage requirements, and prepared IT budgets. The backup and recovery drill applies that planning experience to a sample office.

## Run the demo

Read the [inventory and budget](inventory-budget.md), then run `python3 restore_drill.py` for a local recovery exercise. Record the elapsed time and integrity result when repeating the exercise on the planned infrastructure.

See the [backup architecture](architecture.md) for the data flow and retention schedule.
