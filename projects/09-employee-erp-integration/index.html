              How it works

              One engine, tested

              The validation, planning, apply and undo logic is a single JavaScript module with no user interface. The browser console and the 15 automated tests run exactly the same code.

              Fictional data

              A seeded generator creates a 200-person organization and eight weekly HR extracts with hires, transfers, terminations, rehires and realistic data-entry mistakes. The first five weeks were processed with the engine to build the ERP state and run history shown here.

              Safe by design

              Nothing is written until a run is approved. Every applied field is logged with its old and new value, and each run keeps a snapshot so it can be undone. Changes stay in this browser tab; reloading resets the demo.
