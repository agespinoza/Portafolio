# Inspection Duration Model Pipeline

Train a small linear regression model to estimate inspection duration from checklist size. Compare it with a training-mean baseline using a fixed holdout split.

## Career context

My work with data science teams and my MLOps coursework inform this portfolio extension. The demo trains, evaluates, and versions a small model on synthetic data.

## Run the demo

Run `python3 pipeline.py`. The pipeline writes a versioned model JSON and an evaluation JSON to `artifacts/`. See the [evaluation summary](evaluation.md) for the reference run.
