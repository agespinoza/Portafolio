# Inspection Trends in Power BI

Review weekly inspection duration and exceptions by station using eight simulated records. An inspection qualifies as an exception when it fails or takes more than 35 minutes. An inspection that meets both conditions counts once.

## Career context

At Opus, I used Power BI in work to improve access to vehicle inspection data. This report follows weekly duration trends and station-level exceptions using simulated inspections.

## Run the demo

On Windows, open [Inspections.pbip](Inspections.pbip) in Power BI Desktop with Power BI Project and enhanced report format support. Select **Refresh** to load the embedded data. The report contains a weekly trend and a station exception chart.

[The weekly report](inspection-report.csv) can be opened in Excel or any CSV reader. In Power BI Desktop use **File > Export > Export to PDF** for a visual export. The sample has three exceptions, two at South and one at North.

See [Microsoft's Power BI Project documentation](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-overview) for project setup.
