# Mortgage Workflow Automation

Advance a simulated mortgage application through submitted, under review, and approved stages. Each successful transition records an activity event.

## Career context

At NOVA Home Loans, I developed workflow applications with C#, ASP.NET, and SQL Server and collaborated with application support and BI teams on ERP improvements. The sample mortgage workflow demonstrates stage transitions and activity tracking.

## Run the demo

Install the .NET 8 SDK and run `dotnet run --urls http://localhost:5080`. Open that URL, advance the sample application, and inspect its activity log. Restarting the process resets the in-memory demo.
